Tampermonkey · Chromium 122+ · v6.8.4

网页加速器 — 让 Chrome 秒开下一个页面

Chromium 自带一个「提前准备下一个页面」的能力，只是几乎没有网站用它。这个油猴脚本以用户脚本的形式，替所有网站补上这段规则：指针悬停在链接上，目标页已经在后台渲染好，点下去直接呈现。

  • Speculation Rules API
  • 同源预渲染
  • 跨域预取
  • 零依赖 · 无上报
安装到 Tampermonkey 源码仓库

需要先装 Tampermonkey（Violentmonkey 亦可）。链接触发的是安装请求，不是下载文件。

它做了什么

鼠标移到链接上→ 浏览器预渲染目标页→ 点击→ 页面即刻呈现

Chromium 的 Speculation Rules API 接受一段 JSON 规则：匹配到的链接会在后台被预取（只取文档）或预渲染（整页跑起来）。配合 eagerness，可以在「用户只是路过」和「用户真的要打开」之间取一个平衡点。

问题在于，愿意在自己站点上写这段规则的网站很少。这个脚本做的是把这段规则注入到每一个你访问的页面——它不代理流量、不改动请求、不拦截内容，只是把这个原生能力打开。

特性

同源预渲染站内链接整页预渲染，跳转几乎瞬时完成，加速主力
跨域预取外站只取文档、不执行脚本，开销更低；可单独关闭
三档强度conservative / moderate（默认）/ eager
自动排除download、nofollow、下载包与图片直链、页内锚点、副作用链接
自定义排除关键词（logout、cart、token…）与域名黑名单，一行一条
隐私信号分离DNT / GPC 只约束跨域预取，同源预渲染不受影响
仅桌面启用触屏设备自动跳过，避免无谓流量
零外部依赖不加载 CDN、不上报数据；设置面板是原生 <dialog>

安装

  1. 安装 Tampermonkey（或 Violentmonkey），并打开扩展的「开发者模式」。
  2. 点上面的安装到 Tampermonkey，在扩展弹出的页面里确认。
  3. 打开任意网页，控制台出现下面这行即表示生效：
[网页加速器] Speculation Rules 已提交。

装好后无需配置。点击 Tampermonkey 图标可看到三个菜单项：一键开关（会重载当前页）、加速器设置（强度 / 排除域名 / 排除关键词）、查看运行状态（规则是否注入、是否被 CSP 拦截、当前 nonce 与排除模式）。

只启用一个版本。仓库里保留了多份历史文件，同时启用会重复注入规则。6.8.4 更换了 @namespace，会被 Tampermonkey 当成新脚本，升级需手动装一次 —— 装完把「排除域名 / 排除关键词」粘回去、禁用旧条目即可（不必删除）。

注意事项

  • 带副作用的链接不能被推测。预渲染会真实执行目标页脚本，预取也是真实的 GET 请求。登出、加购、删除、支付、一次性 token 类链接都会被真的执行或消耗——默认关键词表覆盖常见情况，站点特殊路径请自行补进「排除关键词」。
  • 跨域预取使用真实 IP，并消耗流量。介意可在面板里关掉「跨域 Prefetch」，站内加速不受影响。
  • 严格 CSP 的站点可能拦掉规则。规则由脚本注入，受 script-src 约束；脚本会复用页面 nonce。若站点既无 nonce 也未启用 'inline-speculation-rules'，规则会被拦下，「查看运行状态」里会标出。
  • 覆盖不了 SPA 路由。history.pushState 驱动的软导航不在 API 范围内。

常见问题

和 instant.page 有什么区别？

instant.page 主要做 <link rel="prefetch">，只把 HTML 取到缓存里；这个脚本用的是 Chromium 新的 Speculation Rules API，站内链接可以整页预渲染（连 JS 都跑完），点击时是切换而不是加载。跨域则只预取文档，不执行对方脚本。

会拖慢浏览器或费流量吗？

默认 moderate：悬停约 200ms 才动手，Chrome 同时最多保留 2 个预渲染，FIFO 淘汰。省流量模式、电量过低、内存紧张时浏览器会自己降低强度甚至忽略规则。默认只在桌面启用，且可一键关闭。

会影响网站统计或登录状态吗？

预渲染确实会真实执行目标页脚本，所以带副作用的链接必须排除——脚本内置了常见关键词表，你也可以自己加。跨域预取只取文档、不执行脚本，且 DNT / GPC 信号会跳过跨域。

为什么有时候看不到效果？

先看「查看运行状态」：规则被 CSP 拦掉、站点是 SPA、或者目标页本身很重，都会让收益变小。也可以在 DevTools 的 Application → Speculative loads 里直接看浏览器有没有真的预取/预渲染。

English

Chromium Speculation Accelerator — a Tampermonkey userscript that injects Speculation Rules into any page, so Chrome/Edge 122+ prerenders same-origin links on hover and prefetches cross-origin documents. No background service, no telemetry, no dependencies; settings live in a native <dialog>. Side-effect links (logout, cart, one-time tokens), downloads, nofollow and in-page anchors are excluded by default, and DNT/GPC only gate cross-origin speculation.
